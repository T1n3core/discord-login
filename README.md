# Discord Login & Registration UI Recreation

A school exercise recreating the visual design of Discord's login and registration pages.

## About

This project was created as a graded school assignment. Its purpose is to demonstrate front-end web development skills through an accurate visual recreation of Discord's login and registration forms.

The project focuses on reproducing the original interface's layout, styling, typography, form fields, and overall appearance using HTML, CSS, and JavaScript.

## Features

- Discord-inspired login page
- Account registration form
- Responsive page layout
- Form interactions and visual feedback
- Page transitions
- QR code login section recreation

## Technologies

- HTML5
- CSS3
- JavaScript

## Disclaimer

This project is an educational exercise and is not affiliated with, endorsed by, or associated with Discord Inc.

The website is a visual demonstration only. It does not provide real Discord authentication or account registration.

## Purpose

The project was developed for a graded school assignment to practice front-end development and recreate an existing website interface as accurately as possible.
